# AI Cyber Risk Prediction

An AI-powered cybersecurity risk prediction system that estimates the **Attack Probability (AP)** of software vulnerabilities by combining vulnerability intelligence from **NVD**, **EPSS**, and CVSS metrics.

The project focuses on building a machine learning pipeline for predicting whether a vulnerability is likely to be exploited, helping security analysts prioritize remediation efforts.

---

## Features

- CVE data preprocessing and cleaning
- Merge CVE information with EPSS scores
- Feature engineering for vulnerability prediction
- XGBoost-based Attack Probability prediction
- Model evaluation using multiple performance metrics
- Export trained model for deployment
- Predict risk for new CVE records

## Dataset

The training dataset is generated by combining multiple public cybersecurity intelligence sources.

### Data Sources

- National Vulnerability Database (NVD)
- Exploit Prediction Scoring System (EPSS)
- Known Exploit Vulnerability - CISA KEV
- CVSS v3.1 Metrics
- CWE Information

Example features include:

- CVSS Base Score
- Attack Vector
- Attack Complexity
- Privileges Required
- User Interaction
- Scope
- Confidentiality Impact
- Integrity Impact
- Availability Impact
- EPSS Score
- EPSS Percentile
