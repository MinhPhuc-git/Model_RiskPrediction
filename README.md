# 🛡️ AI Cyber Risk Prediction

An AI-powered cybersecurity risk prediction system that estimates the **Attack Probability (AP)** of software vulnerabilities by combining vulnerability intelligence from NVD, EPSS, and CVSS metrics.

The project focuses on building a machine learning pipeline for predicting whether a vulnerability is likely to be exploited, helping security analysts prioritize remediation efforts.

---

## ⚙️ Features

- Automated bulk CVE intelligence collection from Wazuh CTI.
- CVE data preprocessing and cleaning.
- Merge CVE information with EPSS scores.
- Feature engineering for vulnerability prediction.
- XGBoost-based Attack Probability prediction.
- Model evaluation using multiple performance metrics.
- Export trained model for deployment.
- Predict risk for new CVE records.

# Machine Learning Based Cyber Risk Prediction

An AI-powered cybersecurity risk prediction system that estimates the **Attack Probability (AP)** of software vulnerabilities using Machine Learning. The project integrates **Wazuh**, **Cyber Threat Intelligence (CTI)**, **NVD**, **EPSS**, and **CISA KEV** to help security administrators prioritize vulnerability remediation.

---

# 📊 Dataset

The training dataset is generated by combining multiple public cybersecurity intelligence sources.

## Data Sources

- National Vulnerability Database (NVD)
- Exploit Prediction Scoring System (EPSS)
- Known Exploited Vulnerabilities (CISA KEV)
- CVSS v3.1 Metrics
- Common Weakness Enumeration (CWE)
- Wazuh Cyber Threat Intelligence (CTI)

## Example Features

- CVSS Base Score
- Attack Vector
- Attack Complexity
- Privileges Required
- User Interaction
- Scope
- Confidentiality Impact
- Integrity Impact
- Availability Impact
- EPSS Score
- EPSS Percentile

💻 Usage

1. Fetch Vulnerability Data from Wazuh CTI

Collect CVE information in bulk from Wazuh CTI.

The input can be:

- `.txt` file (one CVE ID per line)
- `.csv` file (contains a `cve_id` column)

> **Note:** Future versions will automatically retrieve Vulnerability Detection data directly from the Wazuh Manager, replacing the current `cve_list.txt` testing file.

Windows (PowerShell)

```powershell
python ".\CTI_Collector\cti_collector.py" `
    --input ".\CTI_Collector\cve_list.txt" `
    --outdir ".\CTI_Collector\cve_data"
```

Linux / macOS

```bash
python "./CTI_Collector/cti_collector.py" \
    --input "./CTI_Collector/cve_list.txt" \
    --outdir "./CTI_Collector/cve_data"
```

Features

- Automatic retry mechanism
- Multi-threaded downloading
- Resume interrupted downloads
- Duplicate CVE detection
- Bulk CTI collection

---

2. Train the Machine Learning Model

Run the training script:

```bash
python train.py
```

> Replace `train.py` with your actual training script if different.
